# Independent frozen-H2 check (2026-09-25)

This is an exploratory challenge to the proposed interpretation of the H2 depth-alias audit. It changes no encoder or world weights and does not train on fork labels. The checkpoint and latent-cache manifest hashes are asserted in `frozen_refit.py`; the loader also enforces the full source and execution identity. Run with `TRITON_F32_DEFAULT=ieee`, as recorded in the checkpoint.

## Protocol correction

`h2_alias.py` calls a four-frame window with depth one the "gate protocol." That window contains **three observed frames plus one generated frame**. The actual H2 fork gate pre-fills **four observed root frames**, then calls `advance` once (`d4mj/lewm_diagnostics.py:_fork_readouts`). This diagnostic uses a **five-frame window with a depth-one suffix** for factual terminal examples, matching the gate's four-observed-plus-one-generated position. The first, mismatched run is retained in `result_l4.json` and `fork_check_l4.json`; it is not the result below. The original head's failure survives the correction: its mean P(death) on a generated actual death is 0.055, and its paired death-vs-alive10 AUC is 0.505.

## Frozen-world refit

`frozen_refit.py` samples 800 TRAIN and 400 DEV terminal episodes (fixed seed), takes the terminal frame, previous frame, and frame ten steps earlier, and generates each as the final depth-one successor. It fits three fresh heads of the canonical continuation-head capacity, with TRAIN-only feature standardization and inner TRAIN selection, separately on generated features, real successor features, and root features plus the recorded action. DEV had already been inspected in the agent audit and in the superseded L4 run, so this remains exploratory. Pairwise AUC is within the same episode; it measures factual discrimination, **not** all-action safe choice. Full per-episode scores and script hash are in `result.json`.

| DEV paired AUC, 400 episodes | death vs alive10 | death vs predeath |
|---|---:|---:|
| checkpoint head on generated feature | 0.505 | 0.565 |
| fresh generated-fit head, mean of 3 seeds | **0.681** | 0.599 |
| fresh root-feature-plus-action head | 0.661 | 0.545 |
| fresh real-successor head (hindsight) | 0.860 | 0.883 |

The generated refit improves death-vs-alive10 over the checkpoint head by **+0.176 [0.111, 0.236]**, paired episode bootstrap. On the harder immediately-preceding frame the gain is **+0.034 [-0.023, 0.094]**, unresolved. Generated minus root-plus-action is **+0.020 [-0.017, 0.059]** on alive10, also unresolved; it is +0.054 [0.008, 0.103] on predeath. Real successor still exceeds generated by 0.179 and 0.284 respectively. Case-control sampling and positive weighting make absolute predicted probabilities uncalibrated; only ranking is read here.

## All-action fork check

`fork_check.py` applies those three generated-fit heads, without further fitting or selection, to the previously inspected 54,000–54,395 block (`observe_fresh_v5`): 4,072 roots, 804 one-step opportunity roots, including 479 zombie-adjacent opportunities. It uses the evaluator's four observed frames, all 17 `advance` calls, the same expected-safe-choice metric, and episode-seed-clustered intervals. This is **exploratory**, because this block was already inspected for the T-world comparison. Full scores, action counts, model/source hashes and intervals are in `fork_check.json`.

| Opportunity roots | checkpoint head | generated-fit heads, mean | always DOWN |
|---|---:|---:|---:|
| all 804 | 0.475 | **0.547** | 0.613 |
| zombie-adjacent 479 | 0.221 | **0.373** | 0.533 |

Refit minus checkpoint: **+0.071 [0.032, 0.109]** overall, **+0.152 [0.102, 0.205]** on zombie roots. Refit minus DOWN: **-0.067 [-0.135, +0.002]** overall, **-0.160 [-0.248, -0.065]** on zombie roots. The original head chose SLEEP on 594/804 opportunities; refitted seeds chose it on 332–348/804. It remains a frequent wrong choice.

## Reading

The frozen H2 world carries **some** one-step terminal-proximity signal that its checkpoint head fails to use; therefore "the world contains no death information" is false. A head-only correction gives a real, paired improvement, so the supervision shortcut is consequential. But the gain is primarily on the easier ten-frame contrast, the generated state remains far below the real successor on the immediate contrast, and the refitted head still fails the planner-relevant zombie action-choice test. The depth alias is **one defect, not a complete explanation of H2's gate failure**. An alias-free bridge retrain is a controlled causal test of that defect, not a demonstrated LeWM repair.

## Reproduce

From the repository root, using the existing `.venv` and the checkpoint's recorded float32 setting:

```sh
TRITON_F32_DEFAULT=ieee .venv/bin/python artifacts/experiments/20260925_h2_independent/frozen_refit.py
TRITON_F32_DEFAULT=ieee .venv/bin/python artifacts/experiments/20260925_h2_independent/fork_check.py
```

The `_l4` scripts and JSON files preserve the superseded context-mismatch run with exact matching script hashes. It should not be used for the verdict.
