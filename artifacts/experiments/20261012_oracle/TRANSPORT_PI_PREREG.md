# Persistent state + inferred transformations (PI) vs soft regeneration (IC): Track B preregistration

2026-10-15 evening. Written before any PI training. Track B: test an architectural principle, not tune the T platform.

## Principle

Keep the persistent state intact; change it only through explicit, inferred transformations. Every change is a hard
decision that must pay its description cost:
- the camera scroll (deterministic, from the action);
- chance reassignments (the IC posterior);
- deterministic edits (an MDL-gated per-cell edit).

Nothing is regenerated by default.

## Evidence that motivated it (all measured before this document)

- **Recursive fading is structural.** Exact copies keep persisting-mob scores at 0.76-0.83 at depth 16 vs 0.37-0.50 for
  CorrT's soft blend. Supplying the chance outcome does not stop soft fading (R14, R15).
- **Persistence must be a trained decision.** Using CorrT's argmax or its confident weights as decisions spreads wrong copies
  and makes mixed exact/soft rollouts unstable (zombies ×3-4) (R15, R16).
- **Synthetic** (`persist_toy.py`): when the deterministic target keeps unexplained variance, soft regeneration loses all
  mobs by depth 16 (count 0.001-0.06). Persistent state + MDL-gated edits keeps them (0.88-1.01) (R16).
- **Rendering drift is unpredictable from history** (R15), so persistence keeps the stale appearance and treats the drift as
  nuisance.

## Arms

- **pi:** `20261015_whiteboard/pi_model.PIWorld` + `pi_train.py`. Same exact D parent, frozen Raw encoder, causal backbone,
  chance operator and IC v3 posterior (model prior). The deterministic afterstate is an exact copy under a hard global
  scroll, plus hard MDL-gated edits (generated token = the parent's own `proj(belief)`); entering cells are always
  generated. Losses:
  - scroll: cross-entropy toward the parameter-free scroll estimate of the real frames;
  - chance: the IC soft canonical cross-entropy;
  - gate: BCE toward the edit posterior;
  - point: the D loss through T̂ and the edits.
  - No simulator labels.
- **ic (control):** the existing TRANSPORT_IC v3 runs (`transport/ic_seed{1,2}`). Same parent, the same window / Gaussian /
  Gumbel generator seeds, 3,000 updates. PI is trained in a separate process, so GPU numerical nondeterminism makes this an
  across-process comparison (as with the S5 replicate). Disclosed.
- Seed sets 1 and 2; 3,000 updates; batch 16; L16; phase AdamW.

## Readings (bright evaluation roots; both seeds; 3,000 updates)

**Primary (recursion, 8 samples, H16):**
- **P1:** persisting-mob score at depth 16 higher than IC's by ≥ 0.15 (IC: 0.37-0.38 for seed 1).
- **P2:** cow census at depth 16 closer to 1 than IC's.
- **P3:** seen-terrain error at depth 16 ≤ IC's + 1.0pp.
- **P4:** phantoms per frame ≤ 0.05 at every depth.

**One-step (frozen evaluator, both readers):** valid ≥ 90%; duplicate and absent ≤ 5%; static ≤ max(free, 0.5%); all-source
valid movement ≥ 15%; cow valid movement ≥ 20.5%.

**Verdict:**
- **"Persistence principle supported"** if P1-P4 and the one-step conditions hold at both seeds.
- **"Persistence helps but decisions are wrong"** if P1 holds but P3 or P4 fails, as with the argmax copies.
- **"Not supported"** if P1 fails.

**Secondary:** zombie census, camera consistency, pursuit, decision proxies, edits and scroll accuracy over training,
entering-terrain error.

## Known limits

- **Rendering:** copied cells keep the stale appearance, and the point loss sees the drift as residual at copied cells,
  with no parameters to fit it there. Readers were fit on real tokens, whose rendering varies.
- **Scroll:** CorrT's per-cell freedom (e.g. HUD rules, partial moves) is replaced by one global scroll plus edits.
- **Memory:** addressing is unchanged (screen-slot Mamba). That is a separate Track B question, not tested here.
- One budget, no tuning. Fresh confirmation stays sealed.
