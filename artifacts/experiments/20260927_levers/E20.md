# E20 — factual support and consequence alignment, preserving Long Mamba

Declared 2026-10-07 before pool encoding and world optimization. Existing campaign;
output artifacts in `artifacts/eda/levers_e20_v1`, logs in `artifacts/eda/levers_logs`.
No process writes NOTEBOOK. Core architecture, encoder and canonical gates unchanged.

## Evidence and separating contrasts

E19 fresh-arrival support: 15 distinct damage transitions, 111 draws, four observed
frames retained on only 28 draws. Its full-token health dose did not repair fresh
hits. Endpoint latent-L1 selection depicts 0/31 fresh hits, while recorded-health
selection within the identical frozen Mamba families depicts 10/31 and 8/31.
E17 established useful same-slot recurrent memory, but all 63,414 sampled deaths
were at row15; changing only the last time embedding causally changes damage output.

The independently completed full factual TRAIN census finds 36,068 ordinary >=2
damage transitions at t>=14, 8,071 deaths, 2,891,130 unchanged and 59,619 other
transitions. These are source transition counts, not fresh-arrival counts. Fresh
coverage is measured before permitting world training.

All arms continue their own E17 Mamba seed7/8 checkpoint (L16, corrt, fixed Raw
patch encoder). No architecture, whitening, stochastic channel or fork-supervised
world objective is introduced.

| arm | ordinary damage support | objective |
|---|---|---|
| A | distinct targets from the old E19 TRAIN pool | latent L1 |
| B | all eligible factual TRAIN ordinary damage targets | latent L1 |
| C | exactly B's data, contexts, batches and initialization | B + scalar health-change L1, lambda1 |

Death, unchanged and other target sets are identical across A/B/C. Unchanged set
is capped at24,576 and other at4,096 by fixed seed20261007; death and old ordinary
targets are not capped. The A set excludes E19's held main windows. Every target
has t>=14: extract true frames t-14..t+1 and outgoing actions t-14..t. This recovers
history from the source corpus instead of padding or retaining a split fragment.

Training:6,000 updates per arm,40 targets/update (2 death,10 ordinary damage,
26 unchanged,2 other), canonical phase AdamW/lr/warmup/clip/bf16 as E19.
One observed context length per update,4..15, shuffled in each12-update cycle.
Every class appears in every batch with identical counts; thus class prevalence
is exactly independent of final scan/time position, not merely uniform death counts.
Source identities are paired by shared uniform draws within each class. A/B/C
death/unchanged/other targets are literally identical; B/C are entirely identical.

The teacher term uses inverse sampling weights to preserve E19's measured target
class mass [0.0532475,0.0129825,0.912445,0.021325]. Expanded event sampling increases
independent support without silently multiplying its expected teacher-loss share.
Predict only the selected factual next state; all observed history reaches that
prediction. This changes supervision granularity from the historical teacher loop.
Parent-to-A therefore combines continuation, corrected layout/history and objective
granularity. It is explicitly **not** an isolated causal test of terminal alignment.
B-A isolates the expanded ordinary-damage target distribution, not fresh support
alone. C-B isolates the added scalar consequence objective.

C's fixed reader is fitted only on factual TRAIN health-token63 features and health
labels checked against exact renderer HUD templates in every TRAIN frame. Episode-
grouped inner holdout and label-range checks are binding. It reads generated token63;
the current-state reference is detached. Loss is mean absolute normalized health-
change error (health/9), averaged equally across the four target classes. No newly
trainable decision head can bypass the generated state. This is a task-specific
diagnostic objective, not VaGraM or canonical LeWM. The independent historical HUD
reader remains binding in evaluation to detect gains specific to the loss reader.

## Admission and evidence rules

Before world optimization:
- Corpus/splits/source bytes verified against the canonical dataset contract.
- Every event identified by (episode_id, outgoing step), deduplicated; TRAIN only.
- Expanded ordinary targets include at least200 detector-estimated fresh-hit events
  spanning100 episodes. Report unchanged/fresh controls too. No threshold retuning.
  This detector is an audit approximation, not simulator truth or inference input.
- Original and newly fitted health readers have explicit real-successor controls.
  New reader episode-held MAE<=0.15 health units and >=98% ordinary-hit detection at
  the historical1.5-unit cut; otherwise C is held, not silently given another head.
- Exact class/position balance, causal input/target/action alignment, finite actual
  Mamba gradients, B/C data equality, C-B loss identity, and serialized optimizer/
  RNG restart parity verified. Source/reader/pool/parent contracts are hash-bound.

Full states every500 updates; atomic chunked pool/eval outputs; immutable completed
checkpoints; automatic resume rejects changed inputs or sources. GPU jobs serialize.
Nonfinite or contract failure stops the affected queue, preserving its failed state.

Endpoint: all seeds/arms evaluated at observed windows4/5/15, teacher and self-fed
health; ordinary/fresh/cooldown-negative/unchanged/recovery/starvation strata;
historical independent real-fit HUD reader plus the factual loss reader. Same reused
diagnosis panel and paired episode-cluster intervals; not a fresh promotion gate.
Primary strict hit cut1.5, sensitivity0.5 separately. Fresh>=0.5, ordinary>=0.3,
unchanged false<=0.02; both world seeds required. Report whole-world one-step and
depth16 cost. Require one-step increase upper95%<=0.005. Preserve same-slot memory:
paired recall capture lower95% difference from own parent>-0.05 before adoption.
No actor or long-horizon repair claim from endpoint catches. A scientific failure
triggers frozen numerical diagnosis; it never schedules a lambda sweep automatically.

## Literature boundary

[Objective mismatch](https://proceedings.mlr.press/v120/lambert20a.html) and
[VaGraM](https://arxiv.org/html/2204.01464v1) motivate separating consequence error
from generic reconstruction. Our scalar factual health reader is neither a value
function nor VaGraM. [IRIS sampling](https://github.com/eloialonso/iris/blob/main/src/dataset.py)
motivates checking position correlations; its sampling does not guarantee ours is
balanced. The exact batch construction, not a paper analogy, supplies that proof.
